# MirrorCoding Android

Release channel for the PI Mobile Android companion.

## Current release: 0.15.11

Download PI-Mobile-0.15.11.apk from this repository's Releases. Windows
installers and Portable packages belong to AR307/PI-Desktop, not this channel.

- Package: xyz.mirrorcoding.pi.mobile; versionCode: 3.
- Android 7.0 or later; the desktop must be running and online.
- Sign in to the same MC account, then claim the desktop project/session pairing code.
- Includes synchronized model, group, mode, reasoning, Fast and Ultra controls,
  image generation and expandable ReturnToParent subagent result cards.
- Application source: [AR307/PI-Desktop, tag v0.15.11](https://github.com/AR307/PI-Desktop/tree/v0.15.11/apps/mobile).

## Installation and signing

Install over 0.15.1 without uninstalling to retain app data. This release-variant
APK uses the same certificate as the previous distribution. That existing
certificate is an Android debug certificate; the app is not debuggable.
Do not attach signing keys, tokens or private test data to a release.

[Latest release](https://github.com/AR307/Mirrorcoding-APP/releases/latest).
